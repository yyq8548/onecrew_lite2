安装或升级主程序及配套 Codex 插件，核对实际运行程序哈希。需要完整重启 Codex 时说明已完成的步骤，重启后继续通过 live MCP 验证。打开工作台、状态卡和资料库时使用 Codex 内置浏览器并复用对应标签页；实际读取页面后再确认显示成功。点击状态卡按钮会向 Codex 发起打开请求，请处理这个请求并回读页面。

默认连接我平时使用的 Chrome 和官方 OpenCLI 扩展，在工作台明确选择并授权浏览器身份，沿用已有网站登录。需要账号登录、扩展权限或系统权限确认时让我接手。发生错误时读取日志定位，不放宽权限、不改安全设置、不要求安装编译工具。未经明确确认，不开始搜索或发送邮件。最后说明已完成的检查和仍未完成的项目；Mac 验收保持未完成。
