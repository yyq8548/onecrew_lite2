# onecrew_lite 0.7.1 登录检查与搜索错误修复

日期：2026-10-15。任务：QB-3448。代码评审阶段，尚未构建或安装包含本次修复的新正式客户端。

## 行为

- 搜索开始前执行现有 Library 就绪检查，验证授权状态和账号一致性；失败时保留已存任务，返回具体错误，不启动新的搜索执行。
- Library 未登录、正在授权、授权服务不可用分别返回对应错误；只有已验证的账号 ID 不一致时报告账号不同。保留独立授权协议和凭据边界。
- 补充关键词失败时保留允许显示的协议错误码，分别提示 Codex 登录、不可用、超时、计划无效等问题。没有可用平台或新查询时进入需要补充证据状态。
- 产品理解和关键词生成明确将“苹果手机”作为 Apple iPhone 整体理解，不编造具体型号；实际模型调用仅生成计划理解，不执行平台搜索。
- 网页同步与启动错误显示明确原因，去掉重复的通用启动失败提示。

## 验证结果

- 已登录本机 Codex 的实际模型调用通过：识别“苹果手机”，内容方向为使用体验、功能演示和选购建议，没有水果或果园内容。
- 真实 Library 0.1.4 在隔离数据目录启动，未登录时握手返回 `library_login_required`；测试通过后已停止隔离服务。
- Rust `discovery_read_failure_keeps_the_safe_protocol_reason` 通过，验证错误码保留。
- 网页错误映射测试 4 项通过；TypeScript 检查和生产构建通过。
- Rust 测试链接存在体积较大的异常展开信息警告；网页构建存在大 chunk 警告。两者均未阻止检查完成。

截图中的 `query_expansion_failed` 未携带原始错误，不能据此确定同事电脑上的唯一失败原因。上述修复提供准确预检和诊断，不宣称已在同事电脑复现全部故障。
