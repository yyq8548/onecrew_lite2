onecrew_lite Windows 未签名测试版

这是用于客户试用和验收的版本，不是已签名正式发行版。
面向 Windows 10/11 的 x64 电脑；本轮本机验收不代替客户新电脑验收。
安装包包含工作台、动态表格和程序运行所需的资源，无需自行安装 Node.js、Rust 或开发工具。
AI 生成计划、评分需要本机 Codex 登录可用；网站搜索需要联网、Chrome 和搜索连接配置。

安装和首次使用
1. 先安装并登录 Codex，准备 Chrome。双击本包安装程序，按向导完成安装，无需输入命令或安装开发工具。
2. 本包未签名，Windows 可能显示未知发布者或阻止运行。请先向提供者确认文件来源和 SHA-256；遇到组织策略拦截时联系提供者，不要关闭杀毒或安全策略。
3. 安装结束时保留“运行”勾选，首次入口会联网准备搜索组件并连接 Codex，可能需要几分钟。看到“准备完成”后，完全退出并重新打开 Codex。若没有勾选“运行”，双击桌面“onecrew_lite Test”即可开始首次配置。
4. 新建 Codex 对话输入“打开 onecrew_lite”，显示状态卡、工作台和动态表格。按页面提示登录你自己的账号。
5. 在工作台“连接登录”中按提示连接 Chrome 扩展、选择搜索用的浏览器身份并登录平台账号。日常双击桌面“onecrew_lite Test”即可打开两个页面。首次配置失败时保留窗口，将上方报错截图发给提供安装包的人；修正网络或安装 Codex 后可从桌面入口重试。
6. 在“搜索”中填写商品或目标，确认生成的计划后开始搜索。点击“打开搜索结果表格”查看结果。

已有 onecrew_lite 的电脑
安装器不会覆盖已有主程序。已有本测试版可先卸载再安装；已有其他开发版、安装失败或提示文件正在使用时，请联系提供者协助处理。
程序固定安装到当前用户的 AppData\Local\onecrew_lite\bin，以保持工作台、Codex 和动态表格的路径一致。
安装不会自动开始搜索，不包含任何原开发者账号、登录状态、计划数据库或浏览器资料。

卸载
从 Windows“已安装的应用”中卸载“onecrew_lite 未签名测试版”。
若提示动态表格仍在运行，请重启电脑，在重新打开 onecrew_lite 之前卸载。
卸载仅移除安装器放入的程序文件和快捷方式，保留计划、表格和账号数据。
如曾连接 Codex，可在 Codex 中停用或卸载 onecrew_lite 插件；本卸载器不会擅自改写 Codex 配置。
