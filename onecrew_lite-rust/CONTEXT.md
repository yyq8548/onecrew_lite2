# onecrew_lite

onecrew_lite 中创作者档案、联系途径与用户确认相关的统一业务词汇。

## Language

**Creator（创作者档案）**：
onecrew_lite 维护的创作者资料，统一关联其平台身份、联系途径和业务记录。
_Avoid_：平台账号（指整个 Creator 档案时）。

**发现候选**：
通过平台内容或账号线索识别、供本次需求筛选和审阅的对象。发现候选不是已保存的 Creator，展示候选也不等于保存。

**匹配判定**：
依据本次用户要求及已确认的解释，判断候选是否符合入选条件。符合、不符合与待核实是不同结论；匹配数量不是内容命中数，也不是优秀等级的人数。

**评分**：
候选或 Creator 的既有 0–100 评价数值。未评分为空，与零分不同；按档位评价时，用约定的代表值表达所选档位。

**评估等级**：
按评分所在区间解释出的优秀、良好、中等或较低展示分档。等级表达推荐程度，不自动改变入选条件；未评级表示没有评分，不等于较低。
_Avoid_：独立的第二份评分、匹配通过（指评估等级时）。

**评价理由**：
针对某一候选或 Creator，以其自身证据解释匹配结论、评估等级及相关限制的说明。共用评价准则不意味着共用评价结论；不同对象可以同档，但理由不能脱离各自事实。

**联系途径**：
用于识别、访问或联系 Creator 的账号地址、邮箱、网站或社群入口等信息。

**业务邮箱**：
用户授权 onecrew_lite 使用、用于业务邮件收发的己方邮箱。它不是 Creator 的联系邮箱，也不是用户登录 onecrew_lite 时使用的账号。
_Avoid_：Creator 邮箱、登录账号（指己方业务邮箱时）。

**邮箱授权连接**：
用户对特定邮箱授予的一组访问能力及其有效状态。连接成功不等于已经同步邮件，也不等于批准发送任何邮件。
_Avoid_：发送确认、已同步（指授权连接成功时）。

**业务往来范围**：
本次允许处理的业务联系人、邮件线程及历史时间范围。它不等于邮箱的全部历史，也不因服务商授予较宽的读取能力而自动扩大。

**邮件同步检查点**：
某个业务邮箱在既定业务往来范围内已可靠处理到的位置。它不是邮件身份，也不能代替另一邮箱或另一服务商的处理位置。

**邮件发送回读**：
发送后向服务商核对已接受邮件的过程。回读成功不等于收件人已收到或已读，回读失败也不证明邮件没有发送。

**平台原生资料**：
平台读取直接返回的、该平台自有的资料、标识和计数；它不是 Creator，读取它也不会改变 Creator。
_Avoid_：Creator 资料、profile snapshot、provider 事实（指平台读取结果时）。

**搜索范围**：
一项明确的平台读取及其平台操作、连接和搜索条件。它不是 Creator 保存确认项中的展示选择范围。

**搜索计划**：
一个临时确认项，列出一个或多个搜索范围。确认只授权计划中已审阅的搜索范围及其相同条件的后续分页，不授权新增范围、改变条件、Creator 保存或其他写入。
_Avoid_：全局免确认、后续所有操作已授权。

**平台失败证据**：
平台操作失败时，平台或协议原生给出的失败事实，例如 HTTP 状态、RPC 码、原生错误码，以及是否拿到了平台响应。onecrew_lite 不为它另起类别名。
_Avoid_：失败分类、错误类别（指第三方失败时）。

**用户问题**：
为下一项决定补足只有用户能提供的信息或偏好。问题答案不产生确认授权，也不批准后续写入。

**确认项（review）**：
一次提交给用户审阅并确认的拟执行内容。一个交互结果可以依次包含多个确认项；一个搜索计划确认项可以列出多个搜索范围。确认当前项不等于确认后来未列出的范围或后续确认项。

**展示选择范围**：
当前 Creator 保存确认项向用户提供的 Creator 条目及联系途径选项。

**确认授权（grant）**：
用户确认某个确认项后产生的执行资格，范围限于该项已经审阅的内容。搜索计划的确认授权是临时的，只覆盖计划已列出的搜索范围及其相同条件分页。
_Avoid_：执行结果、保存成功（指尚未执行的授权时）。
