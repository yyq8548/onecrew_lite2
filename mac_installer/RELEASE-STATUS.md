# OneCrew Lite 0.9.4 · Mac ARM64 · R1

本地交付修订，保留知乎和小红书 OpenCLI 搜索、作者身份、主页与正文读取，复用原 Chrome 登录。保留原搜索和评分逻辑、证据校验及具体失败原因，未知粉丝数保存为未知。仅打包供 Mac 升级使用，未上传公司仓库、npm 或网站；源码包含本地未提交改动，以发布记录的源码摘要和程序哈希核对。

0.9.4 包含原 R4 的小红书搜索跳转路径末尾斜杠、原生粉丝最终判断和公开主页联系方式 Library 校验修复。实际小红书测试已搜满10位粉丝至少2,000的AI Agent相关博主；48次主页读取、3次按需正文补读全部成功，结果表格同步成功，没有重复读取成功账号。

本次相关真实材料回归10项全部通过，主程序类型检查及 Library 构建通过。OpenCLI 91项回归保持通过。已有旧版 Library 迁移、身份与数据保留验证继续有效，搜索与评分规则保持原状。

本版包含 0.9.2 R2 的修复，将 Codex 配套插件的兼容版本、生成版本和校验前缀统一取自当前产品版本，支持安装、启用和验证 `0.9.4+codex.<摘要>`。插件内容摘要、原生程序哈希和数据目录校验继续保留。

新增 `library-migrate`，支持两种已有安装：

- 已有 `account-*` 目录：保持账号库、Vault、主密钥及端口，迁入完整独立 Library。
- 旧 Rust 根目录：备份和升级原 Creator、Vault，完整迁入 Library，验证原账号与安装身份后原子发布统一数据指针；旧安装保留为恢复来源。

迁移验证全部原表格和行的内容摘要、tenant/base 归属及原安装的在线身份。独立服务或数据库仍有 writer 时拒绝迁移；重复执行已完成迁移返回 `current`。候选健康检查不会修改原 Library 的排队搜索记录。

安装指南适用于 ZIP 与 npm 的数据切换；客户端连接采用迁移返回的实际数据、Vault 和密钥路径。所有安装验收均保持搜索停止。

版本、源码提交、源码摘要、依赖锁摘要、程序和 ZIP 的大小及 SHA-256 以同名 `.release.json` 和包内 `runtime-manifest.json` 为准。Mac 候选为 `productionReady=false`，使用 ad-hoc 签名，未经过 Apple 公证。

本版本通过 GitHub 的 Mac ZIP 升级，npm 的 0.9.3 不含此次修订。本次仅更新我们的 GitHub，未部署公司端。Windows 安装包、Pro 和公司其他功能配置保持原样。本机安装后的数据与界面验收记录单独保存在工作区验证报告中。
