# OneCrew Lite 0.9.9 · Mac ARM64

移除知乎的搜索、登录入口、主页和正文读取、评论采样及专用适配器。旧任务执行时排除知乎，继续搜索和故障恢复入口不再选择它。

适配器更新时，把旧安装中的 `onecrew-zhihu` 移入现有备份目录，活动目录不再保留它。

保留读取历史材料所需的数据定义、作者绑定和评分依据。已有账号、表格、证据、评分和搜索结果保持不变，其他平台沿用现有搜索和评分逻辑。

安装必须保留原账号、安装身份、主密钥、表格、证据和搜索结果，检查完整 `0.9.9+codex.<摘要>` 插件版本及本机程序哈希。安装验收保持搜索停止。

版本、源码提交、源码摘要、依赖锁摘要、程序和 ZIP 大小及 SHA-256 以同名 `.release.json` 和包内 `runtime-manifest.json` 为准。本包使用 ad-hoc 签名，未经过 Apple 公证，标记 `productionReady=false`。

0.9.9 为本地版本，尚未发布官网或 npm。Windows 分发目录、Pro 与公司配置保持原样。
