# OneCrew Lite 0.9.6 · Mac ARM64 · R2

本修订修复知乎正文读取，使用已登录浏览器文章或回答页中的原生作者和正文数据。TikTok 接受请求成功且视频字段有效的结果，保留 HTTP 失败、登录、风控与作者校验；抖音复用原解析器并等待同页结果，避免 MutationObserver 节点错误。

联系页导航与已保存联系人投影共用归属规则，排除明确的嘉宾和推广资源，保留原始证据。推荐目标达标后，工作台和状态卡单独显示可选联系方式补充进度；用户暂停保持暂停状态，分平台任务逐一判断目标。

宿主任务改为按任务持久保存。首次使用新存储时验证账号归属并导入原 `tasks.json`，保留原文件和完成回执；不自动恢复任务。已有有效评分继续复用。仅当新计划经过审查、明确没有职业条件时，LinkedIn 跳过额外职业专项审查；旧计划及不确定情况仍保留审查。

MCP 工具目录在构建时生成并纳入包完整性清单。页面表达式会在恢复原始语言后读取；任意语句与代码块保留原有执行语义。现有知乎、小红书、Library 迁移及配套插件修复继续保留。

安装必须保留原账号、安装身份、主密钥、表格、证据和搜索结果，检查完整 `0.9.6+codex.<摘要>` 插件版本及本机程序哈希。安装验收保持搜索停止。

版本、源码提交、源码摘要、依赖锁摘要、程序和 ZIP 大小及 SHA-256 以同名 `.release.json` 和包内 `runtime-manifest.json` 为准。Mac 候选使用 ad-hoc 签名，未经过 Apple 公证，标记 `productionReady=false`。

LinkedIn、Facebook 联系页只在实际达到截取上限时标记截断；微博完成长文读取后保存真实完整性，读取失败保留具体原因。真实知乎文章与回答、TikTok、抖音、联系页和微博回归通过，适配器测试 107 项、主程序相关测试 22 项和类型检查通过。小红书按用户要求跳过本轮登录验收。

R2 为本地修订，尚未发布官网或 npm。Windows 分发目录、Pro 与公司配置保持原样。
