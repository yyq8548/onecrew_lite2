# OneCrew Lite 0.9.1 · Mac ARM64 · R32

本目录提供当前源码配套的 Mac 开发候选。准确源码提交、源码摘要、依赖锁摘要、程序与 ZIP 大小及 SHA-256 以同名 `.release.json` 和包内 `runtime-manifest.json` 为准。`productionReady=false`；本次发布位置为个人 GitHub 仓库。

本版包含当前对话模型规划与评分、后台并发及待核实队列调度、成功账号与证据复用、查询反馈调整、95/85/70/40 质量分档、Instagram 的 OpenCLI 页面搜索与 DOM 读取，以及联系页局部失败处理。身份和证据校验、已有结果与评分保留。

连接登录页和搜索页提供“一键修复”。新增 `onecrew_repair` MCP 入口及 CLI `repair` 命令，主 HTTP 服务停止时仍可启动原服务并继续诊断。Codex 插件使用本机生成的完整 `0.9.1+codex.<摘要>` 版本，独立核实启用与加载状态。

安装提示词和指南包含必要安装操作的用户授权、sandbox 阻止后的客户端权限申请、原库备份与升级、安装断点、隔离标记的具体同意步骤，以及客户端重启后的状态卡、工作台和结果表验收。权限由目标客户端和操作系统审批；登录、浏览器授权及必要安全确认由用户完成。

R32 已通过 12 项相关原生检查、818 项前端测试、类型检查、共享接口检查、网页构建和签名验证。本机已实际验证主服务停止后的对话修复及浏览器桥接恢复，六项连接检查通过；原美妆任务的 10 位推荐、53 次读取与原结果表保持不变，搜索未恢复。分发 ZIP 另行执行完整性、解压、签名、原生启动和 live MCP 验证。

Reddit 与 Pinterest 已移除。Google 和 Yahoo 保留登录列表入口，当前不参加搜索，也不在手动搜索设置中显示。其他平台能力以工作台当前状态为准；本次安装包验收不重新搜索平台。

仅提供 darwin-arm64，使用 ad-hoc 签名，未进行 Apple 公证。Windows 安装包、公司 GitLab、Cloudflare、Access 和 R2 下载清单保持原状。
