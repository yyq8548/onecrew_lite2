# OneCrew Lite 0.9.0 · Mac ARM64 · R4 验证状态

本包用于个人 GitHub 分发，保持 `productionReady=false`。本次只更新修复代码、Mac 分发包及相关文档；公司仓库、Cloudflare、Access、R2 下载清单和 `windows_installer` 均未修改。

R4 包含：

- LinkedIn 默认不限粉丝；仅在用户明确要求 followers 或 connections 时检查相应指标，保留自然语言条件中的 AND/OR。
- 身份绑定的主页、当前职位或帖子能够独立证明全部要求时完成评分；只对仍缺证据的账号补充读取帖子。
- 原生联系浮层没有公开联系方式时正常完成；普通空网页仍拒绝。已绑定的联系页网站和电话可进入联系方式列。
- 评分失败项保留原因并释放活动队列容量，支持旧队列恢复；同一失败任务通过准入校验后可直接续跑。
- 要求评分结构或引用无效时允许一次明确的模型修正，保留完整引用校验。
- 保存资料中的邮箱与 Telegram 标签粘连时分别提取，历史误解析值不进入当前联系方式投影。
- MCP 账号分组合同支持系统已有的网站等联系方式类型。

真实验证：同一 LinkedIn 任务从 18 人续跑至 30/30，原 18 人全部保留，28 份成功主页回执没有重新读取。最终为币安 7 人、OKX 8 人、Bitget 相关业务 8 人（含 1 位 Bitget Wallet）、Bybit 5 人、Gate.io 2 人。公开邮箱 3 人，原结果表同步完成，读取预算 83 次。续跑新增 16 次联系页读取全部完成；历史 13 次联系页失败保留，新增一次帖子不可读已记录，未阻断完成。另有 8 人待核实、1 人未进入推荐。

相关应用回归、应用类型检查、MCP 合同、原生 LinkedIn 回执和联系方式回放均通过。此前完成的主界面构建及平台验证沿用相同输入，本次没有重复搜索其他平台。Mac 用户包再次校验 ZIP、全部文件、主程序签名，以及打包源码和资源的一致性。

主程序保留已在本机升级、原账号登录、原数据、原表格和 live MCP 上验证过的相同字节。源码提交、构建快照、字节大小和哈希分别记录在发布清单和包内清单中。Codex 插件完整版本在目标电脑生成，不能套用本机摘要；已安装版本与宿主当前加载的进程分别检查。

安装提示词加入权限预检、`cli.failed` 只读诊断、安装断点及单次重载后的续装步骤。0.7.1 到本版的所有环境兼容性尚未独立验收；一般诊断错误不能作为数据不兼容结论。权限拒绝或必要检查仍失败时保留旧服务与数据并报告具体阻塞。

程序为 ad-hoc 签名，未进行 Apple 公证；Intel Mac 未构建或验收。第三方许可证缺项保留在发布清单，未描述为正式生产发布。Windows 安装包未重建，不声明其已经包含本次源码修复。
