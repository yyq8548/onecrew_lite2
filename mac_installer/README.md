本版移除知乎的搜索、登录入口、读取适配器及相关运行路径。已有知乎表格、证据和评分继续可读，其他平台沿用现有搜索和评分逻辑。保留账号、Library 迁移和搜索结果，安装后搜索保持停止。

请从本目录下载本版 ZIP、同名发布记录、SHA-256 和安装提示词，一起交给目标 Mac 上的 AI。Mac 同时支持 ZIP 与 `@onecrew/lite` npm 安装；安装时使用对应方式的完整提示词，并核对程序哈希和完整 `0.9.9+codex.<摘要>` 插件版本。线上可用版本以公司发布记录为准。

Windows 后续仅通过 npm 分发，旧 windows_installer 保留。本 Mac 包使用 ad-hoc 签名，未经过 Apple 公证。
