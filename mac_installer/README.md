本版提供 Mac 旧版独立 Library 的正式迁移命令，支持 ZIP 安装升级到 npm。迁移保留原账号、安装身份、表格、搜索结果和旧库恢复副本；安装不启动或恢复搜索。

npm 主包与 Mac 平台包为 0.9.2；Windows 继续引用已发布的 0.9.1。Windows 分发目录保持原样。本候选使用 ad-hoc 签名，未经过 Apple 公证，正式部署须经审批。
