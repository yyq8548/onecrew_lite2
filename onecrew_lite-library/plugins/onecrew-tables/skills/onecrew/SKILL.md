# onecrew_lite

通过已连接的 onecrew_lite MCP 工具操作工作区。以当前工具描述和参数定义为准；本 skill 提供扩展流程与示例，MCP 本身不依赖插件或 skill。业务调用需要 onecrew_lite 登录；用 account 检查状态或获取用户在浏览器完成授权的入口，不索取凭据。

涉及动态表格时，先阅读 [动态表格](references/dynamic-tables.md)，再设计列或写入数据。其中包含富单元格类型、字段组合规则和调用示例。


直接使用已连接的 MCP 工具；已有表格的读写不要改用网页操作，不要寻找本机服务源码。连接不可用时明确报告连接问题；不要自行寻找或启动其他同名服务。

完成后用用户能理解的方式报告结果，并提供工具返回的表格详情链接。只有工具成功返回的操作才算完成；不要把已有表或部分完成的工作说成全部成功。
