## 本包行为

- 使用当前 Windows 用户的环境目录，自动检查服务登记、Codex 插件和历史默认目录。唯一旧目录继续使用；多个目录列出候选并要求选择。保留账号、主密钥、表格、端口和浏览器身份。
- 默认连接用户日常 Chrome 中的官方 OpenCLI 扩展，明确授权选中的身份。授权按账号和设备保存。已删除独立浏览器入口及其创建、验证界面。
- 状态卡按钮向 Codex 发送打开请求，由 Codex 获取新的授权入口并复用内置浏览器标签页。发送请求成功不等于页面已显示。
- 计划生成把需求理解和候选计划合为一次结构化模型调用，保留全部需求理解字段。独立模型复核仍单独执行，推理强度、完整查询规则、引用检查、来源覆盖和语言检查保留。相同引用的排除平台分组输出后无损展开，减少重复生成。
- 严格粉丝门槛先核对原文数字，再转换为包含边界的最低值：“严格超过 8000”得到最低 8001；“至少 8000”保持 8000。
- 保留前端 600 秒等待和单请求超时不直接声明服务断线的修复，本次未继续延长超时。
- 统一版资料库读取当前 OpenCLI 状态，接口读取失败显示状态暂不可用，不再据此声明主服务未启动。
