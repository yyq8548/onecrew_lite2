请安装附件中的 OneCrew Lite Windows 版本。

完整解压，阅读 README.zh-CN.md、INSTALL-CODEX.md 和 RELEASE-STATUS.md。先核对发布记录中的 ZIP 大小和 SHA-256，再按 SHA256SUMS.json 校验包内全部文件，确认安装指南的主程序哈希与 candidate.json 一致。校验通过后，按指南直接执行分步安装；使用预构建程序，不安装编译工具。

使用包内 installation-discover 命令自动识别首次安装或旧安装。首次安装使用当前 Windows 用户的默认目录；升级沿用发现的原数据目录、账号、表格、设置和浏览器身份。存在多个数据目录时，列出候选让我选择，不猜测、不清空、不另建空账号。

安装或升级主程序及配套 Codex 插件，核对实际运行程序哈希。需要完整重启 Codex 时说明已完成的步骤，重启后继续通过 live MCP 验证。调用 onecrew_web 获取新入口，在 Codex 内置浏览器复用工作台和当前计划的动态表格标签页；没有计划时打开资料库。明确显示右侧浏览器面板（visibility.set(true)），依次切换到两个对应标签并读取实际内容，最后将工作台标签置于前台，保留表格标签。保留标签页仅表示标签不会自动清理；只有面板可见、目标标签已选中且页面可读，才能报告已显示。点击状态卡按钮时执行同样步骤。工具不可用、仅排队或页面读取失败时报告实际状态。

默认连接我平时使用的 Chrome 和官方 OpenCLI 扩展，在工作台明确选择并授权浏览器身份，沿用已有网站登录。需要账号登录、扩展权限或系统权限确认时让我接手。发生错误时读取日志定位，不放宽权限、不改安全设置、不要求安装编译工具。未经明确确认，不开始搜索或发送邮件。最后说明已完成的检查和仍未完成的项目；Mac 验收保持未完成。
