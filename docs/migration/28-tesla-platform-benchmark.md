# Tesla 博主跨平台实测

测试日期：2026-10-17（UTC）。条件：Tesla 相关账号，粉丝不少于 1000。使用当前安装程序对应的正式 OpenCLI 搜索、资料与正文读取计划，以及同一专用浏览器身份。此次只做验证，没有修改产品源码。

## 测量口径

每平台搜索一次，最多取 5 条结果；按作者去重，顺序读取最多 3 个账号。发现粉丝不足 1000 即提前结束该账号；技术读取失败后停止该平台，不重试。英文平台查询 `Tesla owner`，B站、抖音、微博查询 `特斯拉 车主`；Google、Yahoo 查询 `Tesla owner review YouTube`。

时间单位为秒，测量实际命令执行到返回，不包含人工操作或模型判断。平均读取时间包含低粉早停和真实失败，因此不代表每个账号完整资料的耗时。搜索时间另外列出。成功率只衡量实际发出读取请求的技术结果，不能代表符合条件比例、证据充分比例或长期稳定率。

评分证据检查粉丝、简介、原创正文和公开邮箱；邮箱没有公开时记为未知，不作为拒绝条件。仅有一篇 Tesla 内容可以支持相关度初筛，不能证明长期专注 Tesla。视频正文指页面公开说明或配文，此轮没有取得音视频逐字稿。

## 验收边界与证据位置

本轮能够验证搜索、真实资料读取、低粉提前排除和部分相关度评分证据。各平台没有全部达到完整评分验收：LinkedIn、Pinterest、Reddit 没有读到达标作者；B站正文缺失；Google 返回形态不适合直接评估作者；Yahoo 有真实读取错误；Instagram 的可见粉丝文字与标准数值字段存在衔接问题。Facebook 简介缺失、TikTok 正文稀薄也会限制评分深度。
