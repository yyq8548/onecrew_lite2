# 管理端与资料库连接修复

2026-10-16，本地 TypeScript 开发验证。当前 Mac ARM 程序为 `.scratch/mac-arm-candidate-22/onecrew_lite`，端口保持 53400，实例 `8547b231-9a42-4003-a164-e54afbf4f008`。账号数据库和专用浏览器身份保持原位置。本记录不代表 Windows 实机验收或客户发布。

## 当前行为

- 状态卡的“打开管理端”和“打开资料库”每次点击均调用仅向 App 提供的 `onecrew_workspace_open`。适配器重新核对运行实例，再向相应受控入口签发一次性票据；不使用状态卡保存的裸地址。打开期间阻止重复点击，失败显示明确提示。
- 同一账号和认证代次的有效浏览器会话复用 Cookie、CSRF。未登录的两页也复用有效配对会话，保留已经绑定的登录流程；新票据仍只消费一次。
- 已登录页面每 30 秒在可见时检查真实握手，恢复焦点时也检查；有效握手续期同一个 8 小时会话和 Cookie。无活动超过有效期、服务重启、退出或账号变化仍要求重新授权。
- 短暂网络错误保留已挂载工作区，显示连接中断状态。恢复仅重新读取握手，不重放搜索、评分、写入或发送。
- 403 与普通业务错误保持原始失败；只有明确的本地会话错误清除会话，账号变化单独处理。并发重连合并为一个握手，过时握手不能覆盖已经失效的认证代次。
- 握手和票据兑换均设置 10 秒超时。配对升级与后台检查复用同一握手，避免两个请求互相误判为账号变化。
- 管理端和资料库响应同一标签页的新票据 hash 变化，立即兑换授权；无需手动刷新。资料库同步处理会话错误分类和握手超时。
- 断线页区分连接不可达和会话失效，提供状态卡入口和可复制给 Codex 的打开请求。网页中已移除旧 `onecrew web --no-browser` 指引。
