# 搜索、评分与连接现状

更新日期：2026-10-17。产品版本0.7.1，当前 Mac ARM 本地候选37，尚未正式发布。Windows 和 Mac Intel 需要分别构建并完成本机验收。

## 搜索与评分

- 搜索按平台入口生成关键词，区分账号搜索、内容搜索和网页来源解析。结果保留真实来源、作者绑定及失败原因。
- 简介、发布或转载内容、整理与反应内容、实际观察到的相关标签均可支持主题匹配；仅当用户明确要求原创时检查原创条件。
- 粉丝门槛、语言与额外条件分别按证据核验。未知信息保留未知；公开邮箱是软偏好，未公布邮箱不自动淘汰。
- 已充分取证的账号立即评分；相同材料复用回执，证据变化后才重新评分。评分与读取分别调度，避免反复补读。
- 待核实区分等待评分、缺少正文或身份、读取受阻、补读后证据仍不足，以及额外条件缺口。
- 自动表格同步由新增推荐账号触发；暂停、结束和用户手动要求时同步。同一时间的同步请求合并处理，读取普通资料不单独触发同步。
- 表格粉丝量显示完整数字，例如 `48500`。原始约数和估计范围仍保留在评分证据中，接近门槛时继续核实。

## Instagram

程序通过 OpenCLI 专用浏览器读取正常网页可见 DOM。Codex Computer Use 用于对话中的网页操作与验收，其执行器尚未嵌入客户端。

采集粉丝量、简介、公开邮箱和一篇相关帖子正文。主页保存最多6条实际可见帖子的链接与预览，按任务关键词选择正文并复用链接；预览用于选帖，不作为已核实正文。不额外采集点赞、评论、互动率和发布时间。私密账号跳过，未公开资料保留未知。出现登录、验证码或限流要求时停止。

浏览器读取与资料保存共用帖子预览合同，核实账号、帖子类型、编号与链接；预览允许换行、回车和制表符，并按 Unicode 字符截取。两个真实出错账号的网页返回已加入回归数据；真实任务数据库副本完成保存、回读和候选生成，修复版安装后原任务继续读取并成功保存后续账号。

## YouTube 与其他平台

YouTube 公开搜索不要求预先登录。缺少登录检测信号、历史未登录或过期记录均不自动排除公开搜索；页面实际要求登录、年龄验证或风险检查时按真实结果停止。

其他平台注册入口保留各自可读资料范围。搜索成功、粉丝达标、主题匹配和评分证据充分分别判断；已有样本验证不能证明所有关键词、账号和网站状态下都成功。已稳定取得充分证据的路径不反复外部验收。

## 连接与会话

状态卡分别显示账号、专用浏览器和动态表格连接。工作台与 Library 使用本地授权会话；服务重启或账号切换会使旧会话失效，需要从状态卡申请新的单次授权链接重新打开两页。普通同账号在线复核保留身份周期。专用浏览器复用原绑定和登录资料，重启服务后核实浏览器与扩展连接。

当前服务重启后的页面会话恢复仍依赖新授权链接，不把端口在线作为页面已连接的证明。恢复时同时核对状态卡、工作台及当前任务表格。
