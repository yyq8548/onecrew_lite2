# 搜索、评分与连接行为

更新日期：2026-10-19。当前实现为 TypeScript 0.7.1，Windows 配套构建 candidate-87 / R8.1。实际验收范围见 [当前交接](14-handoff-status-and-next-plan.md)。

## 搜索与评分

- 按平台注册入口生成关键词，区分账号搜索、内容搜索和网页来源。保存真实来源、原生作者身份、资料及正文证据。
- 简介、发布或转载内容、整理与反应内容及实际相关标签可以支持主题判断；用户明确要求原创时才检查原创条件。
- 粉丝、语言和额外硬条件按证据判断。未知信息保持未知；公开邮箱是软偏好，缺少邮箱不阻止其他条件已满足的作者入选。
- 充分材料直接评分，材料不变时复用已有评分。基础条件已满足时，不为用户未要求的评论、字幕、互动率追加读取；平台授权、原生作者归属及正文完整性检查仍保留。
- 待核实明确区分等待评分、必要正文或身份缺失、读取受阻、补读后证据不足与额外条件缺口，失败不会伪装为空结果。
- 新增推荐、暂停、结束或用户手动操作触发表格同步；普通资料读取、审核记录变化和服务重启不重发已同步表格。只读查询恢复已有表格入口。
- 推荐视图只下载需要的作者资料，来源明细在用户打开时读取。粉丝量显示完整数字，原始约数和证据继续保存。

## 平台读取

用户在日常 Chrome 的官方 OpenCLI 扩展中连接并授权指定身份。当前代码不创建独立浏览器；不接管其他浏览器身份，也不读取密码或 Cookie。

Instagram 从实际网页 DOM 保存粉丝量、简介、公开邮箱及相关帖子正文，预览仅用于选择帖子；私密账号、登录要求、验证码和限流分别处理。YouTube 公开读取不因缺少登录检测信号自动淘汰，实际页面要求登录或年龄验证时停止。

各适配器保留原生账号编号、内容与作者绑定、粉丝和简介字段、正文及可用的日期和互动信息。不同平台的可用字段不同，缺失信息不编造；必要证据缺口明确显示。R7 的 11 个实际平台样本及网页来源验证记录保存在安装包验证说明中，不能推断所有账号和关键词均可读取。

## 连接与发送

本地工作台和 Library 使用同一账号归属的授权会话。普通在线复核保留有效会话；服务重启或账号变化后的旧会话明确拒绝，由 OneCrew 获取新的一次性入口恢复页面。状态卡、工作台和当前动态表格同时核对连接与数据新鲜度。

对外发送仅邮件页 Gmail 批量发送，需要用户具体确认，保留去重与未知结果保护。MCP 没有发送能力。后台表格同步继续检查原授权、当前账号及协议，保留失败状态和恢复；不得通过关闭校验掩盖连接问题。

Mac ARM、Mac Intel、宿主状态卡实际按钮及许可证补齐仍未完成。构建与资源检查不能替代宿主和客户电脑的实际验收。
