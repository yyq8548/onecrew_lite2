# 同步触发与表格加载

日期：2026-10-19。Windows x64，candidate-87，客户包 R8.1。对外发送仍只保留邮件页 Gmail 批量发送；本次未发送邮件。Mac ARM 和 Mac Intel 验收保持未完成。

## 已修改

- 调度器只在新增推荐人时发布过程结果，暂停和结束时发布最终进度；保留用户手动同步。前端不因页面打开、读取次数或审核记录变化自动发布。
- 后台同步不再在每次重启时把所有已完成表格重新排队。已排队但未完成的任务继续按原有权限、协议和重试规则恢复。
- 推荐视图不再同时下载隐藏来源明细，也不在元数据变化时重复重载这些明细。
- 表格同步把逐行审计记录写入改成批量写入；事务、租户检查、单元格保护及写后回读全部保留。
- 账号在线验证的三个独立请求并行执行；三项身份与协议检查全部通过后才签发证明，未增加缓存或延长超时。
- 通过只读查询恢复已有表格入口，重新打开工作台不会为了恢复入口而同步。表格读取失败明确显示，不能当成尚未生成。
