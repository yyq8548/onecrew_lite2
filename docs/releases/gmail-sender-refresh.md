# onecrew_lite Gmail 发件人修复

任务：QB-3448。目标分支：公司客户端 main。

## 改动

Gmail 授权刷新发送 email_folders 事件后，同时刷新本地邮箱查询，解决其他窗口保留空发件人缓存的问题。批量发送窗口打开时重新读取本地邮箱，区分读取失败、未连接和邮箱不可发送，并提供重试。

设置页检查发送与读取权限及对应 scopes；权限不完整时提示重新授权。已选邮箱失效后要求重新选择，避免自动切换发件账号。查询失败或发件人失效时禁止继续准备或确认发送。

仅修改客户端前端及类型化命令封装，保留后端发送权限和确认流程。无需数据库迁移、Access 或 Pro 代码变更。
